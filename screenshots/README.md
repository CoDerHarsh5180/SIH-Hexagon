# 📸 Screenshots Directory

Place the captured application screenshots here according to the naming convention below to display them automatically on the main GitHub `README.md`.

## Directory Structure
```
screenshots/
├── light/
│   ├── landing_hero_light.png              # Landing page top section (Hero, flag motif, CTA)
│   ├── public_transparency_dashboard.png   # Public transparency dashboard & live metrics
│   ├── KYA_AI.png                          # Know Your Approvals AI Wizard & Assistant
│   ├── subsidy_calculator.png              # Government subsidy & incentive calculator
│   ├── applicant_dashboard.png             # Citizen / Applicant dashboard with active applications
│   ├── smart_vault_view.png                # Smart Document Vault showing verified files & QR tags
│   ├── local_officer_queue.png             # District officer task queue and document inspection
│   ├── inspection_scheduler_modal.png      # Modal showing inspection date selection & inspector assignment
│   ├── auto_escalation_panel.png           # Auto-escalated tickets with SLA breach indicators
│   └── main_authority_panel.png           # State department macro-analytics and command center
└── dark/
    └── landing_hero_dark.png               # Landing page hero in Dark mode
```

## Capture Tips
- **Recommended Aspect Ratio**: `16:9` (1920 × 1080 px) or browser viewport scaled cleanly.
- **Image Format**: PNG or optimized WebP.
- **Browser Zoom**: 100% (avoid browser scrollbars cutting off major elements).
